# Skill : Catalogue détaillé des skills

> **Description** : détail de chaque skill et de chaque outil du projet appuyé sur un script (sous-commandes `arc_index.py`, rattrapage du matériel Garmin, gabarits de plan…). `AGENTS.md` n'en garde qu'un index d'une ligne par entrée.

## Quand l'utiliser

- Avant d'utiliser un skill ou un outil dont on ne connaît pas encore les options, les garde-fous ou les sorties.
- Quand le client ne liste pas les skills de lui-même (Codex, Gemini CLI, Cursor).

## Pourquoi ce skill existe

Le catalogue détaillé faisait environ un quart d'`AGENTS.md`, envoyé avec chaque requête. Il est désormais chargé à la demande ; le texte est recopié tel quel. Les règles communes (aucune écriture chez Garmin, COROS ou intervals.icu sans « oui » explicite, jamais en headless) restent dans l'index d'`AGENTS.md`.
